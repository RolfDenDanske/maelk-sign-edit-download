MÆLK SIGN EDIT 1.1.1
Minecraft Java 26.3 / Fabric

KRÆVER
- Minecraft Java 26.3
- Fabric Loader 0.20.1 eller nyere
- Fabric API 0.166.2+26.3 eller nyere til Minecraft 26.3

INSTALLATION
1. Luk eller genstart Minecraft, når JAR-filen er lagt ind.
2. Læg maelk-sign-edit-1.1.1.jar i Fabric-profilens mods-mappe.
3. Behold Fabric API i samme mods-mappe.
4. Start Fabric-profilen og åbn et skilt på normal vis.

BRUG
Til højre for skiltet:
Copy  Kopierer alle fire linjer til udklipsholderen.
Paste Indsætter de fire første linjer fra udklipsholderen.

Over skiltet:
Gemmeikonet gemmer de fire tekstlinjer i dit lokale bibliotek.

Til venstre:
Gemte skilte viser dine skabeloner. Klik for at indsætte teksten.
Scroll for at se flere. Brug x på en skabelon for at slette den.

Afslut med Minecrafts Færdig-knap for at sende teksten til serveren.
Gemmeikonet gemmer en lokal skabelon; det lukker ikke editoren.

Biblioteket bevares efter genstart i:
config/maelk-sign-edit/saved-signs.json

Tekst, tomme linjer og mellemrum kopieres. Træsort, farve, glow og
skiltets anden side ændres ikke. Brede linjer tilpasses til skiltet,
og der vises en besked, hvis noget blev tilpasset.
Moddet virker på almindelige skilte og hængeskilte.

Download og hjælp:
https://github.com/RolfDenDanske/maelk-sign-edit-download

24 automatiske tests er bestået. Visningen og serverintegrationen
skal stadig afprøves i spillet. Serverens normale regler for
redigering af skilte gælder fortsat.
